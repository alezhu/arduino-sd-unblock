# Подключение SD / MicroSD модуля к LGT8F328P

Плата на базе микроконтроллера **LGT8F328P** (LogicGreen) по назначению выводов, распиновке и логическим уровням при питании от 5 В **полностью аналогична Arduino Nano / Uno**.

## Сравнение и отличия от Arduino Uno / Nano

| Параметр | Arduino Uno / Nano (ATmega328P) | LGT8F328P |
| :--- | :--- | :--- |
| **Распиновка SPI (CS, MOSI, MISO, SCK)** | D10, D11, D12, D13 (совпадает 1:1) | D10, D11, D12, D13 (совпадает 1:1) |
| **Логическое напряжение по умолчанию** | 5 В | 5 В (при питании от 5 В) |
| **Максимальная частота ядра** | 16 МГц | 32 МГц |
| **Разрядность АЦП** | 10 бит (0..1023) | 10 бит / 12 бит (в скетче используется 10-бит режим) |
| **Работа от 3.3 В** | Требует отдельной платы 3.3V | Поддерживает переключение на 3.3 В на плате |

> [!NOTE]
> Схемы подключения, номиналы резисторов ($1\text{ кОм} / 2\text{ кОм}$) и варианты согласования уровней через микросхему **74HC125N** для LGT8F328P **абсолютно идентичны платам Arduino Uno / Nano**. 
> Подробные схемы приведены в руководстве: 👉 **[Подключение к Arduino Uno / Nano](uno_ru.md)**.
